# Images Folder

## Profile Photo

Place your profile photo here with the filename: `profile-photo.jpg`

**Recommended specifications:**
- File name: `profile-photo.jpg` (or `.png`)
- Size: 400x400 pixels (square image works best)
- Format: JPG or PNG
- File location: `images/profile-photo.jpg`

The portfolio will automatically use this image. If the image is not found, a placeholder will be displayed.

## Project Images

You can also store your project screenshots and certificate images in this folder and reference them in the HTML.
